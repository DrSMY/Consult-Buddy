

## Goal
Make the patient guide (Consultation page → Patient Guide tab) read like the user's AOD-9604 reference: rich narrative intro, structured numbered sections with friendly headings, and detailed support/what-to-expect content. The card UI in `PatientGuideDisplay.tsx` is already strong — the gap is the **content** the DB feeds into it.

## Approach
Two coordinated changes:

### 1. Enrich the per-peptide quick-start content in DB (source of truth)
Rewrite all 15 `patient_quickstart_guide` rows in `clinical_documents` to follow the reference structure:

```
[1-line tagline]

[Analogy paragraph — "Think of X as a ..."]

### 1. Your Dose Routine
- Your Dose: …
- Frequency: …
- Best Timing: …
- The Routine: …
- Optimization: …

### 2. How to Handle Your Medication
- Refrigerate / Storage: …
- Swirl Only: …
- Clear Liquid: …

### 3. Support Your [Goal]
- Hydration: …
- [Synergy supplement]: …

### 4. What to Expect
- Onset: …
- Side Effects: …
```

Done via a migration that updates content for each peptide. Sourced from the existing PeptiDOC clinical references (same style as the AOD-9604 sample). The "Your Dose Routine" section will be **stripped at render time** (existing logic in `Consultation.tsx` already does this) and replaced with the clinician's actually-prescribed dose block — so the patient sees personalised numbers but inherits the rich structure.

### 2. Tighten the renderer + builder (small polish)
In `src/pages/Consultation.tsx` `buildActionPlan`:
- Use `:::: TITLE ::::` delimiters (what `PatientGuideDisplay` prefers) instead of `### Heading` so each new section becomes its own colored card.
- For each prescribed peptide, emit cards: `:::: <PEPTIDE NAME> — INTRODUCTION ::::`, `:::: YOUR DOSE ROUTINE ::::` (personalised), `:::: HOW TO HANDLE YOUR MEDICATION ::::`, `:::: SUPPORT YOUR METABOLISM ::::`, `:::: WHAT TO EXPECT ::::`.
- Keep the analogy intro as a plain paragraph above the cards (renders in the gradient banner).

In `src/components/PatientGuideDisplay.tsx`:
- Add icon/color presets for the new section titles: "YOUR DOSE ROUTINE", "HOW TO HANDLE YOUR MEDICATION", "SUPPORT YOUR METABOLISM", "WHAT TO EXPECT".
- Fuzzy match already covers most; just add explicit keys for the perfect color pairing.

### 3. No schema change required
`clinical_documents.content` is already free-text. Just an UPDATE migration.

## Files touched
- **Migration**: bulk UPDATE 15 rows in `clinical_documents`.
- **Edit**: `src/pages/Consultation.tsx` — rewrite the `patientMedSections` builder to emit `::::`-delimited sections per peptide.
- **Edit**: `src/components/PatientGuideDisplay.tsx` — add 4 new section configs (icons + colors) for the new headings.

## Out of scope
- Weight Loss (GLP-1) guide — generated by edge function, separate flow. Can do in a follow-up if you want consistency.
- KB Doctor View edit UI — already supports editing these rows, so the new richer content is editable post-migration.
