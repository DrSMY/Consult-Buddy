

## Make DOCassist Installable as a PWA

### What This Means
Your app will be installable directly from the browser onto any phone's home screen -- it will look and feel like a native app with your DOCassist icon, splash screen, and offline support. No app store needed.

### What Will Be Done

#### 1. Install PWA Plugin
Add `vite-plugin-pwa` to handle service worker generation and manifest configuration automatically.

#### 2. Configure PWA in Vite
Update `vite.config.ts` to add the PWA plugin with:
- App name: "DOCassist"
- Theme color matching the teal brand palette
- Standalone display mode (no browser chrome)
- Offline caching strategy for assets
- OAuth route exclusion to prevent caching auth redirects

#### 3. Create App Icons
Add PWA icons in the `public` folder:
- `pwa-192x192.png` and `pwa-512x512.png` (generated with DOCassist branding)
- Apple touch icon for iOS

#### 4. Update index.html
Add mobile-optimized meta tags:
- Theme color meta tag
- Apple touch icon link
- Manifest link (auto-generated by the plugin)

#### 5. Create Install Page
Add a `/install` page with instructions for installing the app:
- Detects if already installed
- Shows platform-specific instructions (iOS: Share > Add to Home Screen, Android: browser menu)
- "Install" button that triggers the browser's native install prompt on supported browsers

#### 6. Add Install Prompt to App
Add a subtle install banner or button in the app header so users are prompted to install when visiting on mobile.

### Technical Details
- `vite-plugin-pwa` will be installed as a dependency
- Service worker uses `navigateFallbackDenylist: [/^\/~oauth/]` to avoid caching OAuth routes
- Manifest includes `start_url: "/"`, `display: "standalone"`, and proper icon sizes
- The PWA will cache static assets for offline use while keeping API calls online-only
- New files: `src/pages/Install.tsx`, PWA icon files in `public/`
- Modified files: `vite.config.ts`, `index.html`, `src/App.tsx` (add route), `src/components/AppHeader.tsx` (optional install button)
